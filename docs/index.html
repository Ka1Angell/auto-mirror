Три глотка до свободы

1

v2rayNG

«Группы подписок» → + → вставь ссылку на нужный файл → потяни список вниз для обновления.

2

Throne / Hiddify

Добавь ту же ссылку как подписку — клиент сам заберёт все конфиги и будет обновлять их по кнопке.

3

Без подписки

Открой .txt, скопируй содержимое целиком и импортируй из буфера обмена. Работает всегда.

В режиме белых списков начинай с файла 26 — он собран специально под SNI/CIDR-фильтрацию и проходит там, где остальные молчат.
